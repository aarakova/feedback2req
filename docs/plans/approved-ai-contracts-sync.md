# Фиксация и формализация технических контрактов AI

- Цель и разрешённый этап: документальная фиксация ТК-1–ТК-7 редакции 2,
  исполняемые JSON Schema, примеры и проверки их корректности. Backend, frontend,
  AI-адаптеры, оркестрация и физическая БД не разрабатываются.
- Утверждённые источники: DEC-001–DEC-004; сообщение пользователя от 2026-10-20
  «Утверждаю технические решения ТК-1–ТК-7 в редакции 2…» и последующий ответ
  «А — атомарный сегмент; запретить partially_processed для extract_feedback».
- Известные факты: четыре операции трёх ролей, сокращённая оболочка, разные
  представления оснований генерации и проверки, минимальная связь с удалённым
  источником, включение незавершённых предложений в сравнение, scoped-вопросы.
- Открытые вопросы: провайдеры, стек приложения, физическое хранение, лимиты,
  размер сегментов, эксплуатационная очистка, численные AI-метрики.
- Допущения: новых продуктовых правил и технологий приложения не вводится.
  Python/jsonschema используются только для автономной проверки артефактов.
- Решения пользователя: ТК-1–ТК-7 утверждены; дополнительное уточнение атомарного
  сегмента явно утверждено. Clarification status: READY.
- Компоненты: технические DTO и схемы внутренних AI-контрактов, документация.
- Ожидаемые файлы: docs/AI_CONTRACTS.md; docs/contracts/ai/v1/*.schema.json;
  docs/contracts/ai/examples/; scripts/validate_ai_contracts.py;
  scripts/requirements-ai-contracts.txt; действительно затронутые docs/*.md;
  этот план. Существующий пользовательский diff AGENTS.md сохраняется.
- Проверки: метасхема Draft 2020-12, разрешение ссылок без сети, позитивные и
  негативные примеры всех операций, структурные ограничения и заявленные
  прикладные проверки примеров; локальные ссылки, ревизии, git diff --check;
  независимое совместное ревью спецификации, схем, примеров и проверок.
- Риски: смешение структурной и смысловой проверки; неполный охват; скрытое
  восстановление удалённых данных; ложные дубли собственной редакции;
  несогласованность документа и схем. Нет гарантии содержательного качества AI.
- Необходимые изменения: основной источник спецификации AI_CONTRACTS.md,
  запись DEC-005, необходимые ссылки и уточнения утверждённых открытых вопросов.
- Прогресс: спецификация, девять схем и 72 демонстрационных документа завершены;
  затронутые разделы синхронизированы, DEC-005 и ревизии записаны. Продуктовая
  реализация не начата; прежний пользовательский AGENTS.md не изменялся.
- Результаты валидации: Python 3.12 / jsonschema 4.26.0, девять метасхем
  Draft 2020-12, 88 локальных $ref, 38 schema-positive и 34 schema-negative
  документа, 399 мутаций неизвестных вложенных полей, 20 локальных пар — PASS.
  Негативные документы отвергнуты по ожидаемым ключевым словам; шесть
  структурно корректных application-invalid сценариев показывают границу схем.
  Никакие ожидаемые отказы не выдаются за дефект или успешную проверку приложения.
- Ошибки среды: первая установка jsonschema в песочнице не удалась из-за сети;
  разрешённая установка вне песочницы встретила недоверенную TLS-цепочку;
  feature truststore недоступен без отдельного пакета. Установка завершена
  с PEM-набором доверенных сертификатов Windows, без отключения TLS-проверки.
  Окружение и CA-файл находятся в temp, не являются артефактами репозитория.
- Независимое ревью: отдельный read-only reviewer проверил документацию, схемы,
  примеры и скрипт совместно, повторно запустил проверку. Исправлены отсутствие
  прежних фрагментов в extract-контексте, ошибочное основание конфликтной
  демонстрации и устаревшие формулировки источников. После повторной проверки
  замечаний не осталось. Финальные девять документальных SHA-256 и три набора
  ревизий независимо пересчитаны reviewer и совпали. Проверены 50 локальных
  Markdown-ссылок, неизменность шести AI-инвариантов и синтаксис скрипта;
  git diff --check прошёл. Git сообщает только о будущей LF/CRLF-нормализации
  прежнего AGENTS.md, который в этой задаче не изменялся.
- Ограничения: не проверялись реальная БД/права/актуальность проекта, вызовы
  провайдера или смысловое качество AI; эти компоненты не реализованы.
  AP-01–AP-14 — требования будущему приложению, APP-* — только проверки примеров.

## Architecture change impact

- Approved architecture change: техническая формализация ТК-1–ТК-7 в утверждённых
  логических границах А1–А6; дополнительное утверждение атомарного extract-сегмента.
- Potentially affected documentation: REQUIREMENTS, DOMAIN, ARCHITECTURE,
  AGENT_ARCHITECTURE, DATA_MODEL, API, TESTING, AI_VALIDATION, DECISIONS,
  AI_CONTRACTS, прежние планы.
- Documentation checked: действующие инструкции, DECISIONS, REQUIREMENTS,
  DOMAIN, ARCHITECTURE, AGENT_ARCHITECTURE, DATA_MODEL, API, TESTING,
  AI_VALIDATION и прежние планы; финальные результаты и ревизии проверены.
- Documentation changed: AI_CONTRACTS; REQUIREMENTS/DOMAIN (согласованные
  уточнения глубины/дублей и закрытые открытые вопросы); ARCHITECTURE,
  AGENT_ARCHITECTURE, DATA_MODEL, API, TESTING, AI_VALIDATION (только
  затронутые статусы, ссылки и границы); DECISIONS и этот план.
- Documentation checked and unaffected: прежние четыре плана (история закрытых
  этапов); логические А1–А6, ДМ-1–ДМ-6 и шесть AI-инвариантов без изменений.
  AGENTS, PLANS, .codex/agents и prototype не редактировались.
- Tests potentially affected: существующих тестов приложения нет; разрешены
  только проверки схем и примеров, их не выдаём за интеграцию приложения.
- Tests changed: добавлены схемы, полный manifest примеров и автономный скрипт;
  каждый отрицательный пример связан с ожидаемым структурным/локальным правилом.
  Валидные тесты приложения не ослаблялись: таких тестов в репозитории пока нет.
- Implementation affected: только JSON Schema, примеры и проверочный скрипт;
  код приложения не создаётся.
- Additional approvals required: отсутствуют для утверждённого объёма;
  новые существенные противоречия требуют остановки затронутой работы.
- Synchronization status: COMPLETE для разрешённой документальной формализации
  и проверки артефактов. Будущая реализация приложения и её проверки вне этапа.
