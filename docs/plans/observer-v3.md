## Границы данных и backend-зависимости

Локальные TypeScript модели представления не являются HTTP DTO/AI-контрактом.
Пользовательский режим передаёт unavailable для неподключённых данных. Fixtures
допускаются только на отдельной явно маркированной тестовой странице; они не
импортируются обычным App и не включаются в production entry.

| Область | Что потребуется от будущего согласованного backend |
|---|---|
| Overview | Авторитетные 4 KPI, 3 категории человеческих решений, группы/внимание/утрата оснований, область/полнота результата; не total из material pages |
| Findings | Проект/стабильные id, отдельные тексты/типы/происхождение, состав группы, конфликты, ссылки/доступность свидетельств, связи с требованиями, охват |
| Requirements | Точная текущая/кандидатная редакция, отдельное HumanDecision, доступность/состояния оснований, актуальность проверки, замечания/вопросы/серьёзность/blocking, история; разрешённые операции и условия нового Approved |
| Processing | Реальные стадии/состояния/область/ошибки/частичность и допустимые действия. Технический inspect отдельно от семантических стадий; никаких выдуманных процентов |
| Materials | Текущие DTO сохраняются; будущий processing/reliability presentation отдельно, без фиктивных полей в api.ts |

Имена endpoints и опубликованные схемы будущих подсистем здесь не назначаются.
Нет provider/model вызовов, m02b/очереди, изменений backend и AI-контрактов.

## Оставшиеся отличия и ограничения

- Нет semantic HTTP/aggregate API: на рабочих экранах сохранена композиция,
  но числа/записи/операции честно unavailable. Полноценные наполненные состояния
  показаны только в явно маркированном тестовом стенде.
- В шапке реальные permissions вместо demo role selector; сохранены список
  всех проектов, возврат и собственный ID. В доступе UUID вместо выдуманных имён
  пользователей, так как Access DTO не содержит login/email.
- Формы реальных текстовых материалов встроены в панели. Файлы/медиа/удаление
  проекта и сохранение семантических правок/решений не симулируются.
- Требования сравниваются с предусмотренным прототипом inline list mode;
  необязательная карточная доска не добавлялась. Локальный черновик не сохранён.
- Нет условий version/If-Match для access/rename; прежние предупреждения и
  сверка неизвестного исхода сохранены. Ни один пользовательский текст не
  используется как HTML. Домен/AI-контракты/физическая схема не изменены.
