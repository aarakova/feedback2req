Технические решения: UUID материала и state назначаются до вставки. Обязательный
current_state_id замкнут отложенным FK на свой материал в том же проекте;
обратный FK состояния немедленный. Обе строки сохраняются одной транзакцией.
Существующая Project FOR UPDATE применяется до проверки членства при создании
и согласуется с отзывом access из И1. Общий протокол AI-публикации не вводится.
Введённые человеком состояния имеют автора, timestamptz и origin=human.
Хранение TEXT, без файловой копии. Неподдерживаемые PostgreSQL NUL/суррогаты
отклоняются безопасной 422; содержимое не исправляется и не обрезается.
