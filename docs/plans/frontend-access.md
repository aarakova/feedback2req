# Управление участниками проекта

Основание: явное утверждение пользователем от 2026-10-23 предложения frontend
с уточнениями; DEC-012. Исходный HEAD 6c01d81, чистая выделенная ветка
agents/pasted-text-processing-adf660ee в существующем изолированном worktree.

Объём: Owner-only вкладка, пагинация Access, собственный ID и копирование,
раздельные добавление и изменение Approver, подтверждение удаления,
проверка неопределённых результатов. Существующие API/React/TypeScript,
без backend, worker, миграций, AI-контрактов и новых зависимостей.

Добавление проверяет все страницы до отправки. Найденный участник переводится
в отдельное редактирование без автоматического PUT. Последующую гонку между
чтением и PUT существующий API исключить не может: UI объясняет замену прав
при конкурентном добавлении и возможность восстановления членства при PUT.
Результат потерянного ответа не объявляется успешным; сверка читает страницы
до обнаружения ID или конца, не повторяя запись. 403 Owner-only очищает список
и перепроверяет проект, не объявляя автоматически потерю членства.

Изоляция проверки: только собственные Docker-ресурсы с уникальными именами,
без изменения общих image tags, остановки чужих контейнеров, restart БД
других агентов и обращения к рабочей БД. Commit/push/merge не разрешены.

## Валидация

Реализованы вкладка и hash-маршрут access, список/cursor/reload, ID с реальным
копированием и обработкой отказа Clipboard API, раздельные добавление и
изменение Approver, inline-подтверждение удаления. При найденном существующем
UUID добавление не отправляет PUT; перед сменой Approver перечитывается
членство, обнаруженное изменение требует нового явного действия.

Потерянный ответ блокирует новые записи до явной сверки. Прерывание уже
отправленной записи при повторной проверке доступа также сохраняет
неопределённость. Подтверждённая запись и ошибка последующего чтения
различаются. 403 Owner-only очищает список и перепроверяет проект без цикла
автоповторов; CSRF-ошибка сохраняет проект и ввод. Поздние ответы ограничены
контекстом пользователя/проекта и AbortController.
